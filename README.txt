Верхняя часть обновлена по предоставленному скриншоту: фиолетовая шапка, белый логотип, заголовок, показатели, самолёт, поиск и быстрый выбор городов и дат. Мобильная форма складывается вертикально. Настройки верхней части — assets/top.css. Иллюстрация самолёта отображает область предоставленного скриншота средствами CSS.

Onest — визуальный аналог Tutu Sans. Lora — визуальный аналог Cooper Lt. Файлы и лицензии шрифтов находятся в assets/fonts. Размеры типографики настроены по предоставленным PNG Desktop / Mobile; настройки — assets/typography.css.

В папке preview находятся полные изображения версий для компьютера и телефона.

Кнопка «Войти» удалена. Форма поиска открывает официальный поиск Туту для выбранного транспорта, передавая идентификаторы городов и дату отправления. Авиа также передаёт обратную дату и состав пассажиров; автобусы — количество пассажиров. Для ж/д и автобусов открывается поиск в одну сторону. Справочник городов и форматы ссылок находятся в assets/tutu-links.js; города без идентификатора соответствующего транспорта не предлагаются.

Обновление: скидки выделены красными бейджами и рассчитаны из показанных примерных цен. В карточке стажа — 23 года во всех языках. Подсказки городов и дат на мобильном и планшете расположены внутри своих полей. В справочнике 75 городов: 63 для авиа, 58 для ж/д, 74 для автобусов; это не полный справочник Туту и не гарантия наличия рейса на конкретную дату.

Под отелями добавлен блок «Удобная оплата»: Visa, Mastercard, Мир и Корти Милли. На телефоне карточки располагаются по две в ряд. Стили — assets/payments.css, векторные логотипы — assets/payments. Блок и подпись переведены на три языка. Для обновления GitHub Pages замените index.html и загрузите папку assets целиком.
